# W3Schools-Wissensdatenbank
Programmier-Tutorials von w3schools.com lokal lernen (nur Text, Englisch).

1. Frag, welche Sprachen gewünscht sind. Teilbereiche (parts): python, javascript, html, css, sql, java, cpp, c, csharp, php. Empfehlung: erst mit 1-2 Sprachen starten.
2. Lege eine Wissensdatenbank mit `preset` "w3schools" und den gewählten `parts` an (z. B. name "w3schools-python").
3. Weiter nach dem Skill "wissensdatenbank-anlegen". Der Plan enthält eine `notice`: dem Nutzer vorlesen und seine Bestätigung abwarten.
4. Beim Suchen englische Suchbegriffe verwenden (z. B. "python list comprehension"), die Antwort auf Deutsch geben. Codebeispiele aus den Treffern übernehmen und Quelle nennen.

Hinweise:
- Übungen, Quizze, Zertifikate und der "Try it"-Editor werden bewusst nicht gelernt.
- Pause mindestens 2 Sekunden pro Seite. Eine Sprache dauert grob eine halbe bis ganze Stunde (Schätzung im Plan).
